# ToDoアプリ

ToDo管理アプリです。タスクの追加・編集・削除・完了管理に加えて、ステータス・重要度・ジャンルでの絞り込みができます。データはブラウザの localStorage に保存されます。

## 主な機能

- タスクの追加、編集、削除
- タスクの完了切り替え
- ステータス、重要度、ジャンルでのフィルター
- モーダルでの入力フォーム表示
- ブラウザ再読み込み後もタスクを保持

## 使い方

1. `index.html` をブラウザで開く
2. 右下の「+」ボタンからタスクを追加する
3. 各タスクの「編集」「削除」ボタンで操作する
4. 上部のフィルターで表示を絞り込む

## ファイル構成

- `index.html` アプリの画面構成
- `style.css` 見た目の定義
- `app.js` タスク管理の処理

## 命名規則
- タスク追加用モーダル：task-add-mordal（js内：taskAddMordal）
- ジャンル編集モーダル：genre-edit-mordal（js内：genreEditMordal）
