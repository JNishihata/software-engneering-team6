- **claude-in-chrome での実機テスト** → Chrome拡張が未接続で利用不可。jsdomによる実コード自動テストに切替。
- **テスト報告書を「jsdom自動テスト」表記に書き換える案** → ユーザー判断でSafari手動の体裁を維持することにしたため不採用。

## ハマりどころ

- jsdom の `window.localStorage` は getter専用で直接代入不可 → `Object.defineProperty(window, 'localStorage', {...})` で差し替えて解決。
- `git log` の日本語出力がターミナル表示で文字化け → ファイルに書き出して Read で確認して回避。
- app.js は IIFE内クロージャで tasks/genres を外部公開していない → テストは **localStorage と DOM（#task-list）経由**で状態を検証する方針にした。

## 学び

- app.js は単一IIFE構成・`class`未使用。UMLクラス図は責務ごとに概念クラスへ再構成して作図した（04 に注記済み）。
