## 0. 準備・起動方法

インストールやビルドは不要。以下のいずれかの方法で起動する。

### 方法A：ファイルを直接開く

`index.html` をダブルクリックしてブラウザで開く。

```bash
open index.html
```

### 方法B：静的サーバー経由で開く（推奨）

`file://` で `localStorage` が制限される場合は、ソースコードのフォルダで次を実行する。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000` を開く。

> **動作環境**：最新の Web ブラウザ（Google Chrome など）。データは使用中のブラウザ内（localStorage）に保存される。

## 1. 画面の構成

| 場所 | 名称 | 役割 |
| --- | --- | --- |
| 上部 | ヘッダー | アプリ名「ToDo アプリ」と、右上のメニューボタン |
| ヘッダー下 | フィルターバー | 検索欄・重要度・ジャンルの絞り込み |
| 中央 | タスク一覧 | 締切ごとにセクション分けされたタスク |
| 右下 | ＋ボタン | タスク追加モーダルを開く |

---

## 2. タスクを追加する（FR-01）

1. 画面右下の **「＋」ボタン** を押す。
2. 「タスク追加」モーダルが開く。
3. 各項目を入力する。
   - **タスク名**（必須）：やることの名前を入力する。
   - **メモ**（任意）：補足を入力する。
   - **締切**（任意）：日付を選ぶ。
   - **重要度**：高／中／低から選ぶ（初期値は「中」）。
   - **ジャンル**：一覧から選ぶ。または「新規作成」で新しいジャンルを作る（→ 6章）。
4. **「追加」ボタン** を押す。
5. 一覧に新しいタスクが表示される。

> **注意**：タスク名が未入力のまま追加すると、「タスク名を入力してください」と表示され、登録されない。

---

## 3. タスクを編集する（FR-02）

1. 編集したいタスクの **「編集」ボタン** を押す。
2. モーダルが開き、現在の内容が入力欄に表示される。
3. 内容を書き換える。
4. **「保存」ボタン** を押す。
5. 一覧に変更が反映される（完了状態は保持される）。

---

## 4. タスクを削除する（FR-03）

1. 削除したいタスクの **「削除」ボタン** を押す。
2. そのタスクが一覧から消える。

---

## 5. タスクの完了／未完了を切り替える（FR-04）

1. タスク左側の **チェックボックス** を押す。
2. チェックを入れると完了状態になり、取り消し線などで表示される。
3. もう一度押すと未完了に戻る。

> 完了したタスクは、初期状態では一覧から隠れる。表示したい場合は 8章 を参照。

---

## 6. ジャンルを管理する（FR-08）

### 6-1. タスク追加中に新しいジャンルを作る

1. タスク追加／編集モーダルの **ジャンル選択** で「新規作成」を選ぶ。
2. 表示された入力欄に新しいジャンル名を入力する。
3. **「追加」ボタン** を押すと、そのジャンルが選ばれた状態になる。

### 6-2. ジャンルの改名・削除

1. ヘッダー右上の **メニューボタン** を押す。
2. **「ジャンル管理」** を選ぶ。
3. 一覧から操作する。
   - **改名**：「編集」を押し、新しい名前を入力する。
   - **削除**：「×」を押す。そのジャンルを使っているタスクがある場合は確認が表示され、削除するとそれらのタスクは「ジャンル未設定」になる。

---

## 7. タスクを絞り込む・検索する（FR-06 / FR-07）

- **キーワード検索**：上部の「検索」欄に文字を入力すると、タイトル・メモに一致するタスクだけが表示される（入力するたびに絞り込まれる）。
- **重要度で絞り込む**：「重要度」で 高／中／低 を選ぶ。
- **ジャンルで絞り込む**：「ジャンル」で対象のジャンルを選ぶ。
- いずれも「すべて」を選ぶと絞り込みが解除される。

---

## 8. 完了済みタスクの表示を切り替える（FR-07）

1. ヘッダー右上の **メニューボタン** を押す。
2. **「完了済みタスクを表示」** のチェックを入れると、完了したタスクも一覧に表示される。
3. チェックを外すと、完了タスクは隠れる。

---

## 9. 締切による自動整理について（FR-05）

タスクは締切に応じて、次のセクションに自動で分かれて表示される。

| 表示 | 意味 |
| --- | --- |
| 🚨 期限切れ | 締切が過ぎている |
| 📅 今日 | 締切が今日 |
| 📅 明日 | 締切が明日 |
| 📆 今週 | 締切が今週中（2〜6日後） |
| 📆 来週 | 締切が来週（7〜13日後） |
| 📌 それ以降 | 締切が14日以降 |
| ∞ 期限なし | 締切を設定していない |

---

## 10. データの保存について（NFR-04）

- 追加・編集・削除・完了切替を行うたびに、データは自動でブラウザに保存される。
- ブラウザを再読み込み・再起動しても、タスクとジャンルは保持される。
- データは使用しているブラウザ内にのみ保存され、他の端末やブラウザとは共有されない。
