## 1. 何を作るのか・なぜ作るのか

- **困っていること**：課題や提出物などの「やること」を紙やスマホのメモにバラバラに書いていて、締切が近いものが埋もれて忘れてしまう。
- **作るもの**：ブラウザだけで動き、締切が近い順に自動でまとまって表示される ToDo 管理アプリ。
- **うれしくなる人**：複数の課題やタスクの締切を管理したい学生。

---

## 2. 使う人・関わる人

| 誰 | どう関わるか |
| --- | --- |
| 利用者（学生） | タスクを登録・確認・編集・完了・削除する |
| 開発者（6班） | アプリを開発・保守する |
| （教員） | 成果物を評価する |

---

## 3. やりたいこと（要求の洗い出し）

- タスクを追加できる
- タスクに締切・重要度・ジャンルを付けられる
- タスクを編集・削除できる
- 完了／未完了を切り替えられる
- 締切が近い順に自動で並ぶ
- 期限切れのタスクがひと目でわかる
- 重要度やジャンルで絞り込める
- タイトル・メモで検索できる
- ジャンルを自分で追加・変更・削除できる
- 完了したタスクを隠したり表示したりできる

### 言われていないけど、たぶん必要なこと（潜在要求）


- ブラウザを再読み込みしてもタスクが消えない
- インストールやアカウント登録なしで、すぐ使える
- スマホの画面でも崩れずに表示される

---

## 4. 要求の整理（機能／非機能）


| 種類 | 内容 |
| --- | --- |
| 機能要求（できること） | タスクを追加・編集・削除できる |
| 機能要求（できること） | タスクの完了／未完了を切り替えられる |
| 機能要求（できること） | 締切に応じて自動でグループ分けして表示する |
| 機能要求（できること） | 重要度・ジャンル・キーワードで絞り込める |
| 機能要求（できること） | ジャンルを追加・変更・削除できる |
| 非機能要求（質・条件） | 操作してから1秒以内に一覧が表示し直される |
| 非機能要求（質・条件） | 説明を読まなくてもタスクを追加できる |
| 非機能要求（質・条件） | ブラウザを閉じてもデータが保持される |

---

## 5. 特に大事なもの（優先順位）


- **絶対にほしい**：タスクの追加・一覧表示・完了切替・削除・データの保存（永続化）
- **できればほしい**：ジャンル管理、キーワード検索、重要度／ジャンルでの絞り込み、締切の自動グループ分け
- **今回はやらない**：複数端末でのデータ同期、アカウント機能、締切のプッシュ通知
